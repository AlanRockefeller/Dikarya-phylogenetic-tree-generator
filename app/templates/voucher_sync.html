Voucher Sync

Photograph a printed voucher label (QR code + printed ID) as the last photo of each observation. Voucher Sync reads the code from that photo and writes it into an observation field, so voucher numbers never have to be typed by hand. Nothing is written to iNaturalist until you review the preview and press Apply updates.
