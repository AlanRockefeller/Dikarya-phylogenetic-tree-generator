Collapse a clade

Right-click an internal branch or node and choose Collapse Clade to fold that clade into a single wedge. Collapsing is a display change only: it does not remove sequences, does not change the phylogeny, and does not recompute anything. Choose Expand Clade on the same node to unfold it again.

Select two or more internal nodes (click their circles) and the menu also offers Collapse N Clades / Expand N Clades. If you select a clade and a clade nested inside it, only the outer one is collapsed — collapsing both would be the same single wedge. Collapsed clades are not saved: reloading the page shows the whole tree again.

Prune

Pruning removes the selected sequences (or a whole clade) from the edited tree and from the Edited FASTA download. It does not re-infer the phylogeny: the remaining branches keep the lengths and support values they were given when the tree was built.

Recompute

Recompute takes the sequences that are left and re-runs alignment, trimming and tree inference. Topology, branch lengths and support values may all change. Recompute cannot be undone.

Undo

The Undo button (or Ctrl/Cmd + Z) takes back the most recent change: a collapse or expand, or the last prune, rename, rotation or rooting change. It is a single step, not a full history — after you undo, there is nothing further to undo, and there is no redo. The button is disabled and its tooltip says so whenever nothing can be undone. Starting a Recompute clears the undo point, because the new tree is no longer the tree the saved state describes.
